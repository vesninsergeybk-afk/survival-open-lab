# Лаборатория «Выжившего»

Этот репозиторий — рабочая копия аркады для аудита и доработки.
**Он не является публикацией игры и не должен её заменять.**

- Действующая игра живёт в `vesninsergeybk-afk/survival-open`, ветка `main`, и
  публикуется на https://vesninsergeybk-afk.github.io/survival-open/arcade/.
- Здесь GitHub Pages намеренно **не включён**: по правилам проекта (см.
  `docs/PUBLICATION_POLICY.md`) актуальная сборка существует в единственном экземпляре.
- Изменения отсюда переносятся в основной репозиторий только осознанно, после проверки
  `node --test "arcade/tests/*.test.mjs"` и ручного прогона.

