## Ловушки, стоившие времени

1. `fill()` не доходит до редакторов Gemini и ChatGPT — нужен `keyboard.insertText` или
   посимвольный ввод. Длинные ответы обрываются на ~6 тыс. знаков: дробить на короткие вопросы.
2. Кеш CSS: без `?v=` в ссылке правка не применяется. Отсюда были ложные выводы.
3. Синтетические `KeyboardEvent` из `page.evaluate` не доходят до игрового ввода —
   нужны настоящие `keyboard.down/up`.
4. Кириллица в `.ps1` без BOM ломается: читать через `python io.open(encoding='utf-8')`.
5. `git checkout -- file` восстанавливает из индекса. Если правка была застейджена,
   «откат» вернёт её. Для настоящего отката: `git checkout origin/main -- file`.
